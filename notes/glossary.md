# Từ điển thuật ngữ lập trình

Từ điển sẽ được cập nhật dần. Mỗi thuật ngữ có tên tiếng Anh để bạn nhận ra khi đọc tài liệu, nhưng phần giải thích ưu tiên tiếng Việt đơn giản.

| Thuật ngữ | Nghĩa đơn giản |
|---|---|
| Programming | Lập trình: viết chỉ dẫn để máy tính thực hiện nhiệm vụ |
| Code / Source code | Mã nguồn: những chỉ dẫn người lập trình viết |
| Program | Chương trình: tập hợp chỉ dẫn thực hiện một nhiệm vụ |
| Execute / Run | Thực thi / chạy chương trình |
| Output | Đầu ra: kết quả chương trình tạo ra |
| Input | Đầu vào: dữ liệu chương trình nhận |
| Programming language | Ngôn ngữ lập trình |
| Interpreter | Trình thông dịch: chương trình đọc và thực thi mã theo quy tắc ngôn ngữ |
| Function | Hàm: một nhóm thao tác có tên, có thể được gọi để thực hiện nhiệm vụ |
| Argument | Đối số: giá trị truyền vào khi gọi hàm |
| Parameter | Tham số: tên biến nhận giá trị trong định nghĩa hàm |
| Library | Thư viện: mã có sẵn để sử dụng trong chương trình |
| Framework | Bộ khung phát triển: cung cấp cấu trúc và quy ước để xây dựng ứng dụng |
| Package | Gói: cách tổ chức và phân phối các module |
| Module | Mô-đun: thường là một tệp Python có thể được import |
| Database | Cơ sở dữ liệu: nơi tổ chức và lưu trữ dữ liệu |
| Server | Máy chủ: hệ thống cung cấp dịch vụ hoặc xử lý yêu cầu |
| Browser | Trình duyệt: ứng dụng dùng để truy cập và hiển thị website |
| Debug | Gỡ lỗi: tìm nguyên nhân và sửa lỗi |
| Terminal | Cửa sổ nhập lệnh để tương tác với hệ thống |
| Repository | Kho mã nguồn: nơi lưu dự án và lịch sử thay đổi |
| Commit | Một mốc ghi lại thay đổi trong Git |
| Deploy | Triển khai ứng dụng lên môi trường sử dụng |

Nếu một thuật ngữ chưa được giải thích trong bài học, hãy thêm câu hỏi vào nhật ký học tập.
