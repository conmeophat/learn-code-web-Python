# Dự án 01 — Chương trình Python đầu tiên

**Chặng:** 0 — Làm quen với lập trình  
**Mục tiêu:** hiểu chu trình viết mã nguồn → chạy chương trình → quan sát kết quả.

## Bạn sẽ học được gì?
- Tệp Python có phần mở rộng .py.
- Cách mở thư mục dự án trong VS Code.
- Cách chạy chương trình từ terminal.
- Cách phân biệt câu lệnh, dữ liệu và kết quả đầu ra.
- Cách đọc lỗi đơn giản.

## Yêu cầu dự án

Tự tạo một thư mục dự án trên máy tính với tên dễ hiểu. Trong thư mục đó, tự tạo một tệp Python.

Chương trình của bạn cần:
1. Hiển thị một lời chào.
2. Hiển thị một câu giới thiệu ngắn về mục tiêu học lập trình của bạn.
3. Hiển thị một dòng kết thúc chương trình.

Bạn tự quyết định nội dung các câu chữ. Chưa cần tạo giao diện web, chưa cần nhập dữ liệu và chưa cần dùng thư viện ngoài.

## Cách thực hiện

1. Mở VS Code.
2. Mở đúng thư mục dự án, không chỉ mở riêng tệp.
3. Tạo tệp Python mới.
4. Tự viết các câu lệnh cần thiết.
5. Mở terminal tích hợp trong VS Code.
6. Chạy tệp bằng lệnh Python phù hợp với máy của bạn.
7. Quan sát kết quả và sửa nếu có lỗi.

Nếu máy Windows nhận lệnh py, có thể dùng dạng lệnh: py tên_tệp.py. Thay tên_tệp.py bằng tên thực tế của tệp bạn tạo.

## Câu hỏi tự kiểm tra

1. Phần nào trong tệp là mã nguồn?
2. Lệnh nào yêu cầu Python hiển thị chữ?
3. Khi chạy chương trình, Python làm gì?
4. Kết quả đầu ra xuất hiện ở đâu?
5. Nếu viết thiếu dấu ngoặc hoặc dấu nháy, điều gì có thể xảy ra?

## Tiêu chí nghiệm thu

- [ ] Tôi tự tạo được thư mục và tệp Python.
- [ ] Tôi tự viết các câu lệnh, không sao chép toàn bộ lời giải.
- [ ] Tôi chạy được tệp từ terminal.
- [ ] Kết quả hiển thị đúng nội dung mình mong muốn.
- [ ] Tôi giải thích được từng dòng mình đã viết.
- [ ] Tôi biết tìm thông báo lỗi nếu chương trình không chạy.

## Nộp kết quả học tập

Trong nhật ký học tập, ghi lại:
- Tên tệp đã tạo.
- Lệnh bạn dùng để chạy.
- Kết quả đầu ra.
- Một điều bạn đã hiểu rõ hơn.
- Một lỗi bạn gặp (nếu có) và cách xử lý.

**Lưu ý:** dự án này không được đánh giá bằng độ dài code. Mục tiêu là hiểu được chu trình cơ bản và tự giải thích được việc mình làm.
