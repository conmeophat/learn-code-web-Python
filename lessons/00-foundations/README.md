# Chặng 00 — Hiểu máy tính và môi trường học tập

**Mục tiêu:** hiểu quá trình viết, lưu và chạy chương trình trước khi học nhiều cú pháp.

## Danh sách bài học

| Mã | Bài học | Kết quả cần đạt |
|---|---|---|
| 00.1 | Máy tính làm theo chỉ dẫn như thế nào? | Giải thích được chỉ dẫn, dữ liệu, xử lý và kết quả |
| 00.2 | Mã nguồn, chương trình và ngôn ngữ lập trình | Phân biệt được ba khái niệm |
| 00.3 | VS Code, thư mục, tệp và phần mở rộng | Tạo và mở đúng một thư mục dự án |
| 00.4 | Terminal và PowerShell | Biết thư mục hiện hành và chạy lệnh đơn giản |
| 00.5 | Python và trình thông dịch | Phân biệt ngôn ngữ Python với ứng dụng chạy Python |
| 00.6 | Chạy tệp .py lần đầu | Tự chạy một tệp và đọc kết quả |
| 00.7 | Đọc thông báo lỗi đầu tiên | Tìm tên lỗi, tệp và số dòng |

## Kiến thức phải hiểu
- Máy tính chỉ thực hiện chỉ dẫn theo quy tắc; nó không tự đoán ý định còn thiếu.
- Mã nguồn là nội dung do người lập trình viết; đầu ra là kết quả quan sát được khi chương trình chạy.
- VS Code là trình soạn thảo; Python là ngôn ngữ và môi trường thực thi; NiceGUI là thư viện làm giao diện web.
- Thư mục dự án giúp gom những tệp có liên quan vào một nơi.
- Terminal nhận lệnh từ người dùng và hiển thị kết quả hoặc lỗi.

## Thực hành
1. Mở đúng thư mục học tập trong VS Code.
2. Tạo một tệp có phần mở rộng .py.
3. Viết một lệnh hiển thị chữ do chính bạn chọn.
4. Chạy tệp bằng PowerShell/Terminal.
5. Thử cố ý tạo một lỗi cú pháp nhỏ, quan sát thông báo và sửa lại.
